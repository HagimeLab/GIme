# GIme · 离线刷题应用

GIme 是一款面向 Android
的刷题与复习应用，支持日常练习、错题回顾、收藏整理、模拟考试和自定义题库导入。应用采用本地化运行方式，内置题库、练习进度及个人刷题记录保存在设备上，方便随时复习。

## 功能概览

### 多种学习模式

-   **顺序练习**：按题库顺序逐题练习，适合系统学习。
-   **随机刷题**：从选定题库中随机抽题，帮助巩固知识。
-   **背题模式**：浏览题目、选项、答案与解析，用于快速复习。
-   **错题本**：集中回顾答错或手动标记的题目，并支持批量管理。
-   **收藏题目**：收藏重点题目，之后可以单独练习。
-   **模拟考试**：设置考试题量和时长，在答题结束后统一查看成绩。

### 灵活组卷

组卷时可以组合多个题库，并根据复习目标选择出题方式：

-   按指定总题数随机抽题。
-   分别设置单选题、多选题和判断题的数量。
-   自定义考试时长。
-   在答题过程中查看答题进度，并通过答题卡查看题目完成情况。

### 答题与解析

-   支持单选题、多选题和判断题。
-   提交答案后提供判分反馈，并展示正确答案。
-   支持查看和折叠题目解析。
-   可在题目间切换，使用答题卡查看和定位题目。
-   支持将题目标记为错题或加入收藏。
-   通过文字、图形、动画及可选震动反馈提示答题结果。

### 题库管理与导入

-   浏览题库并按题型筛选题目。
-   导入个人题库，作为独立题库进行练习。
-   支持导入 **PDF、DOCX、TXT 和 Markdown（MD）** 文件；PDF 需带文字层，扫描件会明确提示。
-   识别常见的题干、选项、答案和解析格式；符合识别规则的题目可整理为可练习的题库。
    排版规则与可直接照抄的样例见 [docs/导入指南.md](docs/导入指南.md)。
-   支持从 Android
    系统文件选择器选择题库文件，也支持从其他应用将文件分享或打开到
    GIme。
-   左滑题库卡片可改名或删除；首页「今日待刷」同样支持左滑删除。

### 学习记录与个性化设置

-   在本机保存练习进度、答题统计、错题和收藏记录。
-   提供最近练习、完成情况和正确率等学习信息。
-   支持浅色与深色主题。
-   提供字号、震动反馈、答题后是否自动展开解析等设置。
-   支持清理练习进度及管理个人题目清单。

### 版本更新

应用提供版本检查功能：检测到新版本时，弹窗会显示当前版本、最新版本、发布日期（更新源提供时）和更新日志，确认后再进入下载与系统安装流程。

## 构建与检查

-   `build.cmd`：编译 Debug 与 Release APK。本机的 JDK / SDK 路径写在 `build.local.cmd`（不入库），
    换机器时新建这个文件即可。
-   `tools\check.cmd`：回归检查，包含页面逻辑、题库结构、版本比较与题库文件的安全替换/崩溃恢复。
-   `tools\make-source-zip.ps1`：生成源码交付包，并在生成后校验其中不含签名材料、本机配置、构建产物或口令。
-   `tools\verify-release.ps1`：发布后核对 GitHub Release 附件与本地发布件是否一致。

发布记录（产物指纹、签名证书、对应提交）见 `docs/v1.0.1-发布记录.md`。

## 使用体验

GIme
采用黑、白、灰为主的简洁界面，并提供浅色和深色两套主题。题目、选项、进度、解析及管理面板以卡片和弹层组织，适配手机触控操作。

主要交互包括：

-   横向滑动切换上一题或下一题。
-   通过答题卡查看题目状态并快速定位。
-   使用题库筛选标签切换题型。
-   在错题本中进行选择、批量管理和移除。
-   通过动画反馈主题切换、答题结果、进度变化及列表操作。

## 源码结构

项目由 Android 原生代码和 Web 页面组成：Android
层负责应用容器、系统能力及文件交互，Web 层负责主要界面和刷题逻辑。

  -------------------------------------------------------------------------------------------------------------------------------------------------
  文件或目录                                               主要职责
  -------------------------------------------------------- ----------------------------------------------------------------------------------------
  `app/src/main/java/com/fan/shuatiku/MainActivity.java`   Android 主界面容器；管理 WebView、系统文件选择、外部文件接收，以及 JavaScript
                                                           与原生功能之间的调用。

  `app/src/main/java/com/fan/shuatiku/TextExtract.java`    从支持的文本题库文件中提取正文，供题目识别流程使用。

  `app/src/main/java/com/fan/shuatiku/Updater.java`        处理版本信息获取、更新下载及系统安装流程。

  `app/src/main/java/com/fan/shuatiku/Ver.java`            集中提供应用版本相关信息。

  `app/src/main/assets/index.html`                         主要 Web
                                                           页面，包含界面布局、样式、交互、答题流程、判分、解析展示、题库管理及学习记录相关逻辑。

  `app/src/main/assets/bank.js`                            保存随应用提供的内置题库数据。

  `app/src/main/AndroidManifest.xml`                       声明 Android 应用组件、系统交互入口及应用所需配置。

  `app/src/main/res/`                                      Android 界面资源。
  -------------------------------------------------------------------------------------------------------------------------------------------------

## 技术组成

-   **Android / Java**：承载原生应用窗口，处理系统级交互。
-   **WebView**：呈现应用的主要界面。
-   **HTML、CSS、JavaScript**：实现题目展示、练习流程、组卷、判分、统计、主题及动画交互。
-   **本地存储**：保存个人练习状态和相关数据，支持下次打开时继续使用。
-   **文件解析与 JavaScript Bridge**：连接 Android 文件访问能力与 Web
    页面中的题库导入功能。

## 数据与隐私

GIme
的核心刷题功能以本地数据为基础，内置题库和个人练习记录保存在设备端。题库导入由用户主动选择文件或从其他应用分享文件触发；版本检查与更新功能会访问相应的版本发布服务。

请注意：卸载应用或清除应用数据可能会移除保存在本机的个人题库和学习记录。重要的自定义题库建议自行保留原始文件。
