第1题
题目：这份举例里的单选题，题干可以像这样单独占一行吗？
A. 可以 B. 不行 C. 看情况
答案：A
解析：「题目：」只是标签，导入时会被剥掉；选项挤在一行或者每行一个，都能识别。

第2题
题目：下面哪些是合法的选项写法？
A、A. 开头
B、B) 开头
C、C） 开头
D、带圈数字开头
答案：ABC
解析：选项只认字母 A 到 G，后面的顿号、点号、括号都行；带圈数字不认，请改成字母。

第3题
题目：多选题的答案怎么写？
A. 每个答案字母单独一行
B. 写在同一行，字母连着写，例如 ABD
答案：B
解析：答案里出现两个以上字母就按多选题处理，中间的逗号顿号空格都会被忽略。

第4题
题目：判断题可以不给选项，只在答案里写「正确」或「错误」。
答案：正确
解析：这一题没有选项，App 会自动补成「正确 / 错误」两项，并按判断题处理。

第5题
题目：（填空题）GIme 导入的题库文件存放在 App 私有目录下的 ______ 目录里。
参考答案：banks
解析：填空题不参与自动判分，答完之后由你自己对照参考答案打分。

第6题
题目：（解答题）为什么建议先备份一份纯文本稿？
参考答案：PDF 取字受排版影响，留一份纯文本可以对照排查，分清是排版问题还是取字问题。
解析：主观题的参考答案只在答完后展示，不参与对错判定。

第7题
题目：现有建表语句如下：
```sql
CREATE TABLE t (col1 integer NOT NULL) PARTITION BY RANGE (col1);
```
这段 SQL 建立的是什么类型的分区表？
A. 范围分区 B. 列表分区 C. 哈希分区 D. 未分区
正确答案：A
解析：代码块里的内容会连着上下文一起进题干，围栏那三行本身会被丢掉。

第8题
题目：这一题故意不写答案，用来演示「无答案」会被怎么处理？
A. 正常收录 B. 不收录 C. 收录但不判分
解析：没有答案的题会在导入结果里单独算一项「无答案」，不会被静默丢掉，也不会混进可练习的题目里。
