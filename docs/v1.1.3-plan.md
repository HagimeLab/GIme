把 agent 项目的**计划域**与 **MCP 计划工具面**并入 GIme，并按已交付的首页原型（GIme融合首页原型.html）落地**统一首页**，让"今日待刷 + 进行中方案"合成一张任务 Hero。P0 验收通过的活体发送授权、CDP 通道继续复用。
