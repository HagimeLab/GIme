# GIme v1.0.3

**这一版把更新下载换到国内 CDN，并修掉「点了更新一直卡在 0%」。**

## 为什么换下载源

之前从 GitHub 的 Release 资产下载，那个地址会重定向到
`release-assets.githubusercontent.com`，这个域名在部分网络下直接连不上。
真机实测：`api.github.com` 正常（能检查到新版本），但下载地址报
`failed to connect to github.com:443 after 20000ms`，下载器在后台无限重试，
界面上就一直停在 0%。

## 这一版改了什么

- **改用 jsDelivr 从仓库直出安装包**：安装包随源码放在仓库的 `release/` 目录，
  jsDelivr 按路径直接提供，不再经过 GitHub 的资产域名。
  实测手机端 28ms 就能拿到完整文件（命中缓存后）。
- **多个下载源自动回退**：依次尝试 jsDelivr 的四个入口
  （cdn / fastly / testingcf / gcore），最后才回落到 GitHub 原始地址，
  哪一个通就用哪一个。
- **路径带版本号**：jsDelivr 对同一路径缓存 7 天，固定文件名会导致发了新版还下发旧包。
  现在每个版本是独立路径（如 `release/GIme-v1.0.3.apk`），发布即生效。
- **连不上时不再假装在下载**：先快速探测再交给系统下载器；
  识别「等待重试」状态；长时间无进展自动收尾。
- 下载失败时提供「打开发布页」，可以在浏览器里手动取安装包。

## 实测结果

在测试机上完整跑通了一遍更新：

1. 旧版（1.0.2）点「立即更新」→ 从 jsDelivr 开始下载
2. 进度真实推进：0% → 35% → 93% → 完成
3. 下载到的文件 949,653 字节，SHA-256 与源码构建产物**逐字节一致**
4. 自动拉起系统安装页 → 安装成功，版本变为 1.0.3

## 安装

覆盖安装即可，做题记录和导入的题库都会保留（与旧版同一张签名证书）。
