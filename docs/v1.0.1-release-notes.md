# GIme v1.0.1 发布说明

**改进与修复**

- 修复模拟考试交卷、计时及末题切换相关问题：最后一题只交卷一次，交卷后不再访问已清空的会话。
- 模拟考试中按返回键可选择「继续考试」「交卷」「退出并放弃」；放弃后停止计时，不会再在后台自动交卷。
- 提升从其他应用打开或分享题库文件时的导入稳定性：页面就绪后才读取文件，冷启动与运行中分享都能正确导入一次。
- 优化自定义题库导入时的格式提示和题目统计：只支持 `.docx`、`.txt`、`.md`，其他格式给出明确提示；无答案题数量按原始解析结果统计。
- 改进本地题库保存、删除失败时的状态反馈：写盘失败不会假装导入成功，删除失败不会假装已删除。
- 新增更新弹窗中的版本更新日志：检查到新版本后可查看当前版本、最新版本、发布日期与更新内容，再决定是否更新。
- 优化部分异常场景的提示信息，并在文件过大、文件损坏等情况下给出可读的原因。

## 发布信息

- 版本号：1.0.1（versionCode 2）
- 覆盖安装：沿用现有发布签名，不需要卸载重装，做题记录与题库保留。
- 支持导入：`.docx`、`.txt`、`.md`（不再声明支持旧版 `.doc`）。
