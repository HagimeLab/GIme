## 本版内容

逐条说明在 `docs/v1.0.4-发布说明.md`，这里只记发布侧的账：

- 题库改名补到首页「今日待刷」行；题库卡片与首页行的左滑面板都有「改名 / 删除」，
  两格之间加分隔线。
- 导入认「第 N 题 / 题目： / 答案：」排版；PDF 去掉页末页码，跨行选项按字母拼回。
- 导入格式说明改成 App 内可查看、可整份下载的举例页。
- 返回转场两处：卡片不再空白约半秒；题库页右侧不再闪一下。

### 更新分发：旧版本一律给最高版

- `release/latest.json` 只声明当前最高版本，客户端按段数值比较版本号；
  1.0.0 / 1.0.1 / 1.0.2 / 1.0.3 检查更新都会指向 1.0.4，不做按版本分发的补丁。
- v1.0.0 / 1.0.1 读 GitHub `/releases/latest` 的资产；v1.0.2 起读仓库清单
  （下载走 CDN 多源）。两条路都落到同一个版本。
- v1.0.0 / 1.0.1 的下载走 GitHub 资产地址（302 到 release-assets）；
  部分网络下可能慢，这是旧客户端既有的路径，本版沿用清单给新客户端。
