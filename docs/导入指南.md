# GIme 导入指南

导入只认**文字**，所以能不能认出来，取决于文件的排版而不是文件类型。
PDF、Word（.docx）、txt、md 走的是同一套识别规则——先把文字取出来，再按下面的格式拆题。

## 一句话结论

一份稿子里，每道题写成这样就能稳定导入：

```
第1题
题目：可以列出所有数据库角色的是？
A. \du  B. dr  C. \d
答案：A
解析：\du 是元命令，用于列出所有数据库角色。
```

或者更常见的行首编号式：

```
1、可以列出所有数据库角色的是？
A、\du
B、dr
C、\d
答案：A
解析：\du 是元命令，用于列出所有数据库角色。
```

两种可以混在同一份文件里。

## 逐条规则

### 题号

- `第1题`、`第 1 题`、`第1题：` 都认。
- `1、` `1.` `1)` `1）` 都认。
- 用 `1、` 这种行首数字时，**题号必须基本连续**（允许跳 3 题以内）。这是为了不把题干里
  以数字开头的行（`19 个节点中……`）当成新题。
- 用 `第N题` 时不受连续性限制，从中间截一份（第12题起）也认。

### 题干

- `题目：` `题干：` `内容：` 这几个标签会被剥掉，只留正文。
- 题干可以跨多行，续行会拼进同一道题。
- markdown 的代码围栏（``` 那一行）会被丢掉，围栏**里面的代码行照旧算题干**——
  所以带 SQL / Shell 示例的题可以整块导入。
- 行内代码的反引号、`**加粗**` 的星号会被去掉（界面按纯文本显示题干）。

### 选项

- 每行一个：`A、TCP` / `A. TCP` / `A) TCP`。
- 挤在一行也行：`A. \du B. dr C. \d`（点号后面带空格也认）。
- 只认 A–G。
- 选项前面可以单独写一行 `选项：`，这个标签会被剥掉。

### 答案

- `答案：B`、`正确答案：A`、`答案：ABD`（多选就把字母连着写，逗号顿号也认）。
- 判断题：`答案：正确` / `错误` / `对` / `错` / `√` / `×` / `是` / `否` 都会归成判断题型。
- 主观题写 `参考答案：……`，它**不参与自动判分**，只在答完后跟你的作答一起对照。
- 用红色标注答案的 Word 文档也能识别（按颜色推断，界面上会标出「按原稿红字」的题）。

### 题型

- 默认按答案形态推：一个字母=单选，多个字母=多选，正确/错误=判断。
- 想强制指定，就在题干里写标记：`（单选题）` `（多选题）` `（判断题）` `（填空题）` `（解答题）`
  `（简答题）` `（问答题）`，圆括号方括号都行。**标记优先于猜测**。
- 题干里有 `______` 且没有选项没有字母答案的，按填空题收。

## 什么样的题会被丢

导入完成时会给你一份明细，三类数字分开报：

| 情况 | 处理 |
|---|---|
| 认不出答案的客观题 | 计入「无答案」，不收录 |
| 与前面重复的题（题干+选项完全一样） | 计入「重复」，只留第一条 |
| 主观题（填空 / 解答） | **正常收录**，答完自评，不自动判对错 |

## 导入失败通常只有这几个原因

1. **PDF 是扫描件 / 图片版**——没有文字层，取不到任何字。请先用 OCR 转成文字版，
   或者改成 md / txt / docx。
2. **PDF 加密**——读不出内容，会直接提示，不会假装成功。
3. **老版 .doc**——不支持，请用 Word 另存为 .docx。
4. **答案不在文字里**——比如答案是一张截图、或者只在批注里。
5. **选项不是字母开头**——写成 `①xxx ②xxx` 或 `（1）xxx` 认不出来，请改成 A/B/C。

## 建议的做法

先在电脑上把稿子存成 **.md 或 .txt** 导一次，确认题目数、答案、解析都对；
对得上之后再导 PDF（同一份稿子的 PDF 版）。这样出问题能立刻分清是**排版**问题还是
**PDF 取字**问题——后者往往要靠重新导出解决，改排版没用。
