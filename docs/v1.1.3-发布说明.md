# GIme v1.1.3

> 版本口径：v1.1.2 已发布（提交 5560f75，versionCode 13）；这一整轮 P0–P4 的全部工作都归 **1.1.3**（versionCode 14），
> 中途没有跳号。安装包 `release/GIme-v1.1.3-204e2452.apk`（SHA-256 前 8 位 `204e2452`，13911KB），
> 覆盖安装即可，题库、做题记录、方案、对话历史都不动。

## 一、这一版做了什么（一句话版）

把 GIme 从「一个刷题本」变成「一个能自己动手的刷题助手」：大肥鱼有了真正的 agent 循环、工具面、记忆与诊断，
前端有了整屏对话、可交互卡片和方案域，MCP 侧对齐了 2026-07-28 无状态协议。

## 二、P0 地基（C1–C6）

- **前端拆分**：`index.html` 物理拆成 1 骨架 + `style.css` + 4 个脚本（`app-core/app-admin/app-plan/app-chat`），加载顺序固定，纯移动不改行为。
- **OpenUI 并入**：气泡里的 ` ```openui-lang ` 围栏画成真卡片；卡片动作路由 `send/submit/nav/value/approve/adjust/toggle/insight`，
  `nav` 走白名单，`Select` 用底部面板，焦点保持与挤行防护到位。
- **原生桥加固**：桥方法入参校验 + 回调配对核验，导出《JS桥方法表》（42 个方法与文档逐条对齐，回归里有自检项）。
- **流式性能**：增量 120ms 合并上屏，长回答不掉帧。

## 三、P1 方案域（S1–S5）

- **PlanStore**：方案存在原生侧（`filesDir/plans/plans.json`），`rev` 乐观锁 + 原子落盘；页面不另存一份，
  写冲突先重读再重试一次，冲突不静默。
- **每日提醒**：8:30 / 21:00 两个闹钟，含通知权限入口与省电豁免入口。
  本机 Freeme ROM 开机会把应用置为 stopped、`BOOT_COMPLETED` 不送达，所以每次启动 App 会重挂闹钟（BootReceiver 分支单独验过）。
- **首页统一 Hero**：今日待刷 + 进行中方案合成一张卡；方案库/详情页、四个方案动作（暂停/恢复、调整、提醒、问大肥鱼）。
- **上下文注入**：大肥鱼的系统提示里带上进行中方案与今日完成度。

## 四、P2 Agent 运行时（T0–T6）

- **T0 裸围栏兜底**：模型漏写语言标签的 ` ``` ` 块，只要首行是 `root =` 且调用了已知组件就认成 OpenUI，宁可不画也不留空框。
- **T1 ToolRegistry**：10 个工具的 schema 单一真源，页面、MCP、系统提示共用一份。
- **T2 AgentLoop**：工具循环 + 三护栏（轮次、token 预算、重复调用）+ HITL 预览卡（写答案/写解析/删方案必须先确认）。
- **T3 MemoryStore**：超过 30 条自动压滚动摘要，长期画像（最弱题型、近 7 天正确率、进行中方案、偏好）+ 记忆页。
- **T4 RunTrace**：run/tool/round 三级 span，护栏记账带 `stopReason` / `maxTokens` / `uncounted`，可导出诊断包。
- **T5 金标集**：15 条期望路径全部覆盖，另有三方言 canary。
- **T6 安全收口**：关自动备份、凭据走 Keystore 加密（`enc1:` AES-GCM）、开 R8。

## 五、P3 MCP 协议（2026-07-28）

- 新增 2026-07-28 **无状态**双版本：`server/discover`、`_meta.protocolVersion` + `Mcp-Method` / `Mcp-Name`、MRTR、`resultType` / `ttlMs` / `cacheScope`；
  2025 老版式继续并存 12 个月，`GIME_PROTOCOL=2026-07-28` 切换。
- 口令改为 SecurePrefs 加密存储，界面内可二次确认重置；重置后旧口令立刻失效，logcat 里查不到明文。

## 六、P4 助手体验

- **整屏对话**：首页入口的大肥鱼占满整屏，下拉超过 110px 收回；答题页仍是 74vh 底部上滑。
- **输入框就地展开**：长文本在框内放大编辑（默认随内容长到 96px，展开到 40vh），展开键在框内右下角。
- **回答分块卡**：一次回答拆成「正文 / 执行过程（默认折叠）/ OpenUI 结果」，正文卡带复制，结果卡与正文卡平级不套娃。
- **OpenUI 组件 15 → 19**：新增 `List`、`Steps`、`Callout`、`Chart(bar/line)`；bundle 按官方 `@openuidev/lang-core@1.0.2` 重打，
  导出真实 schema 签名，非法节点消费 `meta.errors` 并在卡底点名，不再静默留空卡。
- **联网搜索默认开**：内置通道按请求透传 `search_enabled`，聊天头部可关；首页新增「学习资料」卡，按错题题型薄弱点一键让大肥鱼联网找 3 份资料。
- **中断自动续跑**：`finish_reason=length` 或空回答在同一气泡自动续写（≤2 次）；坏工具块自动重试 2 次；
  网络类错误自动等待恢复重试（≤8 次，配置/鉴权类不重试）；只说「我可以调用…」不发工具调用时自动催促（≤3 次）；
  只剩半截工具调用时不当答案，另起带工具定义的隐藏续跑（每用户回合 ≤2 次）。
- **思考流不卡**：结构稳定时只向 `.think-body` 文本节点追加 delta，缓存 DOM 节点、跳过布局读取，滚动 100ms 节流；
  真机 40 chunk 从 155–192ms（3.9–4.8ms/次）降到 **2ms（0.06ms/次）**，并且不再把滚动位置跳回顶部。
- **OpenUI 按钮交互**：`touchstart` + `mousedown` 450ms 去重，一次点击只执行一次；`toggle:` 执行后即时改文案/`done` 样式并 toast。

## 七、发布前的视觉与交互收口

- 按 taste-skill（app-screen 规则）复查：inspector 390px 从 **4 FAIL + 1 WARN** 降到 **0 FAIL / 0 WARN**。
  首页标题改 `<h1>`；正文/说明文字统一 ink-2（亮色 ≥4.9:1，暗色 ≥5.9:1）；卡片、方案卡、学习卡、对话控件、答案卡、OpenUI 卡改平面边框；
  学习资料 CTA 降为次操作（首页唯一实心主按钮留给「开始今日/去练习」）；对话头图标热区补到 44px、联网开启改描边环；
  OpenUI `Metric` 去色块改标签+数值+竖线；聊天空态去大虚线框；隐藏滚动条；去掉静态 UI emoji。
- **方案页遮罩残留**：方案页 `.fs#planPage`（950）在遮罩（960）之下，退出对话/面板后遮罩不消失导致整页发灰；
  改为按最上层同步（`syncLayerScrim()`），`.fs` 整页不亮遮罩。
- **Key 模式联网按钮**：`hidden` 被 `.chat-cfg` 的 `display` 盖住，补全局 `[hidden] { display:none !important }`。
- **方案「问大肥鱼」**：改为只打开对话，不填输入框、也不替用户发问（发送由用户决定）。

## 九、已知边界（这一版没做的）

- **T4 新短信登录**：按裁定不做；登录在网页端，与测试机 SIM 无关。
- **T5 真实模型抽样**：只跑了 5/15（不是 15/15）；g15（140 题极端场景）是**带预算尾巴通过**，第 8 轮触发 `BUDGET_ROUNDS`。
- **默认预算**：token 预算 300k、工具轮次 10 是硬闸，超了会收口并记账，不是无限跑。
- **闹钟**：Freeme 开机把应用置 stopped，`BOOT_COMPLETED` 不送达，靠每次启动 App 重挂。
- **MCP 老版式**：2025 版式与 2026-07-28 并存 12 个月后再收。
