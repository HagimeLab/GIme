# GIme v1.0.2

**这一版只修一个问题：点「更新」后一直卡在 0%、下载不了。**

v1.0.1 的更新弹窗能正确显示新版本和更新日志，但点「立即更新」后可能永远停在 0%，
没有任何提示。原因有两个：

1. 国内网络对 GitHub 的下载域名（`github.com` → `release-assets.githubusercontent.com`）
   经常直接连不上，系统的下载器会在后台无限重试；
2. 程序没识别「等待重试」这个状态，把它当成「还在下载」，于是一直转圈。

## 修复内容

- **下载前先探一次**：6 秒内判断下载地址通不通。连不上就直接告诉你，不再让你干等。
- **识别「等待重试」**：这个状态以前被误判为「正在下载」，现在按失败处理，并停止后台重试。
- **卡死自动收尾**：即使连接没断但长时间没有数据，25 秒后也会停止并提示。
- **新增「打开发布页」**：下载地址被屏蔽时，可以一键打开 GitHub 发布页手动下载安装包。
- 修掉「连接中」标题在开始下载后没有切回「正在下载」的问题。

## 如果你仍然下载不了

这是网络环境问题，不是 App 的问题。请用下面任一方式：

- 点更新弹窗里的 **「打开发布页」**，在浏览器里下载 `GIme-v1.0.2.apk`；
- 或在能访问 GitHub 的网络下再试一次。

## 安装

覆盖安装即可，做题记录和导入的题库都会保留（与旧版同一张签名证书）。
