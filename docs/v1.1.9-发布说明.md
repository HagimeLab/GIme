# GIme v1.1.9

> 版本口径：v1.1.8 已发布（versionCode 19，发布件 `release/GIme-v1.1.8-8941ba76.apk`，
> GitHub Release `v1.1.8`）。该版之后到本次定版之间的全部工作归 **1.1.9**（versionCode 24）。
> 安装包由 `signing/gime-release.jks` 签名（与上一版同一张证书），可直接覆盖安装升级，
> 题库、做题记录、方案、对话历史都不动。本次模型与推理框架未改，不带模型资产。

## 一、这一版做了什么（一句话版）

字幕识别的「到底跑到哪了」这件事被彻底收口：进度不再冻住、不再跳变，通知栏、收藏页状态卡、
识别页运行卡三处读同一个数；顺手把两张进度卡改成克制的单色样式，并在所有「取消」前置一道确认。

## 二、字幕识别进度：从「会冻住」到「一直在走」

- **修掉进度台自己停表**：原来进度心跳遇到暂停/转场/未就绪就 `return`，下一拍不再投递，
  之后只有真实进度跳涨才刷新——真机拍到过 54.88% 冻 25 秒、47.93% 冻 15 秒。
  改为独立存活标记，只要进度台开着就永远续投下一拍（250ms），暂停只是跳过当拍。
- **修掉「真值不动就冻住」**：识别一段 9 分钟音频，真实进度每秒只走 0.02 点，两位小数下字面停顿。
  现在追真值与显示值分离：追上之后按 0.15%/秒 匀速自走，封顶 95%，等真实进度跳涨再对齐。
- **修掉一跳一大截**：单拍最多上浮 0.5 点，实测 10 帧 86.63→89.01，每帧 +0.25~0.30，无重合无台阶。
  曾经的「领先真值窗口」（+2.2 / +3.2 点）会撞顶再冻，已废弃。
- **缓存命中不再从 0 爬坡**：命中已缓存音频时直接从 30% 起跑，不再出现 25%→31% 的爬升。
- **阶段词改短**：识别页只写「识别中 / 解码中」，暂停写「收尾中」，不再整句铺满一行。
- **三处同源**：通知栏、收藏页状态卡、识别页运行卡读同一个显示值，JS 侧缓动全删，400ms 一拍。

## 三、界面收口：两张进度卡

- **识别页运行卡重做**：保留「大数字 + 标题分栏」的信息层级，删掉上一版的渐变、扫描光、
  点阵、刻度、发光点——那些装饰堆起来像模板生成的仪表盘。现在是单色实条进度、16px 圆角、
  顶部一组小声波表示「在跑」，暂停时声波压停、数字转灰。
- **收藏页状态卡同语言**：撤掉顶部循环扫描、圆点脉冲圈、条上流光，换成同一组小声波；
  百分比与标题同级加粗，副标题与进度条通栏对齐。
- **深浅主题一套变量**：两处都没有单独的浅色补丁，深色/浅色均真机截图核对。

## 四、取消操作先确认

- 取消识别、删除队列等四个入口统一改为毛玻璃确认弹窗（层级在普通弹窗之上），
  点遮罩可关，误触不会再直接停掉正在跑的批次。

## 五、大肥鱼面板掉帧

- **拖拽高度改写合帧**：原来每次 `pointermove` 都写面板高度，真机 120Hz 下一帧要做好几遍布局，
  面板里上百条消息全部重排。现在合并到一帧一次，且值没变就不写。
- **跨档反馈不再强制回流**：改成 Web Animations 播手柄动画，不读布局、不占同步回流。
- **滑动期间关大投影**：入场/收起那段 220ms 只跑 transform，大模糊投影会每帧重刷，期间关掉。

## 六、存储写入

- **数字与阶段没变就不重写队列**：进度台 0.25 秒一拍，空转写入会一直占着队列锁；
  现在只在值真变化时落盘，进度播报与阶段心跳不再互相抢锁抢盘。

## 七、未做 / 已知边界

- **模型与推理框架本版未动**，因此不带模型资产；Gitee 侧只发安装包，不发模型分卷。
- 通知栏的「取消」动作**无法**弹 App 内确认弹窗（通知 action 走的是系统广播，不经页面），
  目前只有 App 内四个入口有确认；是否改成「点通知先进 App 再确认」待定。
- 大肥鱼面板的入场、全屏旋转动效手感只能靠手指实测，本轮无坐标级取证（adb 无法伪造设备方向）。
- 手机上原装 `1.2.1`/versionCode 22 的旧包来源未定位，App 内「检查更新」会把它当旧版，
  覆盖安装以 code 24 为准。

## 八、发布件

- 出包：`gradle :app:assembleRelease`（R8 + `signing/gime-release.jks`）
  → `release/GIme-v1.1.9-<指纹>.apk`；`publish.ps1` 写入 `release/latest.json`（6 条说明），旧包移出 `release/`。
- 下发：安装包**只作 Release 资产**（Gitee → GitHub 两个源），不进 git 仓库；
  更新检查读仓库内 `release/latest.json`（唯一真源）。
- 兼容：versionCode 24、minSdk 24、targetSdk 36；覆盖升级，数据保留。
- 回归：`tools/check.cmd` 1199 项全绿；`check-release.ps1` 全过。
