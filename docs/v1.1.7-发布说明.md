# GIme v1.1.7

> 版本口径：v1.1.6 已发布（versionCode 17，发布件 `release/GIme-v1.1.6-00f9da69.apk`，
> GitHub Release `v1.1.6`）。v1.1.6 发布之后到本次定版之间的全部工作归 **1.1.7**（versionCode 18）。
> 安装包由 `signing/gime-release.jks` 签名（与 1.1.6 同一张证书），可直接覆盖安装升级，
> 题库、做题记录、方案、对话历史都不动。

## 一、这一版做了什么（一句话版）

把**视频播放器**做成真正能用的一套：加载反馈、设备音量同步、全屏手势调音量/亮度、双击暂停、倍速菜单、长按 1.5×、
播完自动下一集、切页自动暂停回来续播；把**题库列表**重做成整叠卡片并支持左滑改名/删除；按大肥鱼自述的缺口把
**OpenUI 组件从 35 个扩到 43 个**（热力图/日历/时间轴/甘特、雷达/仪表盘/散点/环形、树/面包屑/代码对比 + 语义色），
同时修掉一轮真机上暴露的交互与渲染问题。

## 二、视频播放器（Bilibili 收藏）

- **加载反馈**：全屏 / 小屏加载时都显示居中 spinner，不再空白或原地卡住。
- **设备音量**：音量键从「静音开关」改为可调音量，并且与系统媒体音量一致（Java 侧新增 `biliVolume()` / `biliSetVolume(int)`，走 `AudioManager.STREAM_MUSIC`）。
- **进度预览**：拖动进度条时先显示「欲滑位置」，视频继续播放，松手才真正跳转；全屏中间左右滑也做进度预览。
- **全屏手势**：右侧 1/4 上下滑调音量、左侧 1/4 上下滑调亮度，HUD 竖向显示并分别贴左右两侧（与手势同侧）。
- **亮度同步**：新增 `biliBrightness()` / `biliSetBrightness(int)`，窗口级亮度、免权限，退出 App 自动还原。
- **双击 / 倍速 / 长按**：小屏也支持双击暂停；倍速 1×/1.25×/1.5×/2×（菜单在进度条下方、音量键左侧，可自由选）；长按右侧 1/4 = 1.5×，松手恢复用户设定倍速。
- **切页暂停与续播**：播放中切换到其它页面或退到后台 → 自动暂停并保留播放位置；回来点播放继续（`biliPauseForLeave` + `visibilitychange` + `MainActivity.onPause` → `gimeHostPause`）；重新进入同一视频按历史时间续播。
- **自动下一集**：一集播完自动播放下一集（多 P 切下一 P；单 P 顺收藏夹下一条），默认是播放不是暂停；被无手势拦截时静音兜底再恢复。
- **修复**：小屏切集「无效扩画面」（新视频无元数据时高度塌成方形 → 小屏钉 16:9 + 黑底 + 居中 spinner）；重复点击同一集重载；频繁切集触发 `BiliStream` 并发 503（`MAX_ACTIVE` 3→8 + 切换互斥 + 释放旧流 + error 自动重试）；从「最近观看」进视频后标题显示成视频名（改为所在收藏夹名，旧记录反查）。

## 三、题库与整体 UI

- **题库列表整叠卡片**：默认整叠（deck）状态，点卡片展开详情（进度 + 继续刷 / 背题 / 模拟），再点收起；底部虚线为次级导入入口。
- **左滑操作**：仅「已展开」的卡片左滑露出「改名 / 删除」，按钮改为**纵向**排列（80×38、圆角 12、间距 10），减少横向空间的挤压感；改名走 `#sheet3`、删除走确认弹层。
- **导入题库入口**：原下方大段下划线入口重排为标题行右侧的黑色胶囊「+ 导入题库」；导入面板重做为 格式标签 → 主操作卡 → 次级按钮 → 圆点注意事项 → 进度条 的结构。
- **分类卡片扁平化**：`#tab-bank .cat` / `.task` 去掉拟物双层阴影，改 1px 细边 + 22px 圆角 + surface 底色；筛选胶囊保持纯扁平。
- **交互组件**（按 mobile-advanced-interaction 规范）：滑动确认（清空进度 / 删除方案，阈值 0.85 或 600px/s）、字号旋钮 Dial、成绩粒子、气泡避边；**大肥鱼悬浮球按用户要求移除**。
- **启动行为**：冷启动固定回首页，不再自动进答题页；考试进行中除外。续做仍从首页「继续上次进度」进入。

## 四、大肥鱼 OpenUI 组件扩到 43 个

- 新增：`Heatmap`（打卡热力图）、`Calendar`（月历打卡）、`Timeline`（时间轴）、`Gantt`（甘特条）、`Breadcrumb`（面包屑）、`Tree`（章节树）、`Diff`（改前/改后代码对比）、`Ring`（环形进度）。
- `Chart` 新增 `radar`（雷达）、`gauge`（仪表盘）、`scatter`（散点）。
- 语义色：`Callout` 增加 `danger` 且 success/warn/danger 带内置图标；`Badge` 支持 `tone`。
- 构建链：`tools/openui-bundle/entry.mjs` 定义组件 → `node build.mjs` 重建 `ui/openui-core.js` 与 `ui/openui-signatures.js`（签名 35→43），系统提示已自动带上新组件。

## 五、未做 / 已知边界

- **组件联动（条件渲染 / 读表单值 / 局部状态）**：OpenUI DSL 是静态快照，需要在渲染层引入运行时状态机，属于较大改造，本版未做。
- **Table 的搜索过滤 / 导出**：`sortable` 已有，搜索与导出未做。
- **媒体（音频 / 语音）、白板手写**：按要求不在本版范围。
- 安全相关（debug WebView 调试口、MCP CORS、SecurePrefs 明文降级）按用户要求未处理。
