## 发布安全

- Release 关闭 WebView 调试：`javap` 核对 **release 字节码中 `setWebContentsDebuggingEnabled` 引用数 0，debug 为 1**；真机装 release 后 `adb shell cat /proc/net/unix | grep webview_devtools` **无 socket**，装 debug 后能连上 CDP。
- 源码交付包：`tools\make-source-zip.ps1` 生成后自校验，33 个文件，不含 `.jks`、`keystore.properties`、`local.properties`、`build.local.cmd`、`.git/`、构建产物；并扫描内容确认无本机绝对路径、无口令明文、无私钥（已做负向自检：故意塞一个含口令的文件，脚本必须报错退出）。
- 未更换签名密钥：Release APK 仍由既有证书签名（SHA-256 `d45a2377…`），与 v1.0.0 完全一致。
- 版本一致性：`aapt2 dump badging` 实测 `versionCode=2`、`versionName=1.0.1`。

1. 卸载后装 **v1.0.0 release**（由 `405c1a1` 临时 worktree 构建，`versionCode=1`）。

结论：同签名覆盖安装成功，题库与做题记录均保留。

## 真机验证中发现并修掉的问题

1. **冷启动崩溃**：桌面图标启动时没有文件，`intentOf` 返回 `null`，`ArrayDeque.add(null)` 抛 NPE，App 起不来。已在 `enqueueImport` 入口拦截 `null`。
2. **异常原文外泄**：文件提供方收回权限时，界面显示 `com.fan.shuatiku has no access to content://…`。已增加 `readable()` 翻译层，`.doc`/损坏 docx/无权限分别给出可读文案。
3. **会话卡死**：存档里状态为 `submitting` 时，重启后既不走进度也不收交卷。启动时统一归一为 `running`。
4. **答题页返回箭头绕过**：`exitQuiz()` 未拦截考试，点左上角返回可把计时丢在后台。已让它与返回键走同一道拦截。
5. **saveBank 覆盖失败会丢题库**（发布前复查发现）：原实现先 `target.delete()` 再 `tmp.renameTo(target)`，rename 失败时旧文件已删、新文件没进 —— 题库直接消失。已抽成 `BankStore`：旧文件挪成 `.bak` 而非删除，替换失败或长度校验失败一律回滚，并新增 18 项注入失败的回归。
