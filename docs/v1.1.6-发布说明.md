## 一、这一版做了什么（一句话版）

把「问大肥鱼」从只回一段文字，改成**图文一起讲**：回答自动配 OpenUI 卡片（结论 Callout、对比 Table、趋势/占比 Chart、
流程 Steps、公式 Math、示意图 SVG），卡片本身补到 35 个组件、还能驱动 App；同时把这十几轮真机排错挖出来的交互与渲染缺陷
一并收口（展开卡片串到相邻对话、折叠宽表没有横滑提示、图表 NaN/undefined、停止丢正文……），
再加两条体验改动：退后台回来自动回到上次页面、首页去掉搜索入口。

## 二、改动明细（按主题）

### 1. OpenUI 组件扩到 35 个，且能驱动 App（5df992b、d485192、9ec0038）

- 组件 22→27→35：补 Rich（markdown + KaTeX）/选项组/空态错态/Tab 等渲染类缺口。
- 卡片不再只是「看」：`Tap` 可点、`Chart.action` 点在数据点上、`Table.rowAction` 点行，接上
  `bank / wrong / drill / redrill` 四个动词，卡片能直接把 App 带到题库、错题、练习。

### 2. 真机排错轮一~三（2f9adf2、beca769、6cbc46e、d66874d、a64da5d、d4a6c90）

- **渲染**：卡片文字被负 margin 出血顶出边框（卡片没吃到 `.md` 排版规则）；折叠宽表补「← 这一栏比屏幕宽，可左右滑 →」提示，
  展开时按新增内容重新标记；图表非数值一律 `NaN`/`undefined` → 统一走 `numOf`/`shown`（坏值当 0、标签照原样显示），
  折线 x 轴整格 44px 可点（原来只有 18×14 的小字）。
- **解析失败不再静默消失**：`root` 解析不出来但有 `errors` 时，整卡显示「卡片解析失败（N 处格式问题），请让大肥鱼重新生成一次」。
- **停止链路**：停止时保留已收到的正文、不再亮出源码围栏；改 run epoch 之后，「停止→再发」不会两路并发写同一个会话；
  渲染失败把源码回填进卡片（不再白卡）。
- **存储**：配额分级瘦身并回传失败（不再吞 QuotaExceeded）；字面围栏不截半；多卡表单按卡号分层；超长工具结果截字段保合法 JSON；
  Tab/th/Empty 补 aria。
- **Java**：停止/异常路径 flush 尾巴（原来 ≤23 字的尾巴会丢）；`quote()` 转义 U+2028/U+2029；OpenAiStream 累计参数防双份。

### 3. 大肥鱼改成「图文优先」（ac26cfe、abdb323）

- `chatAgentRules()` 加【回答形态·图文优先】：**允许文字讲解**，但涉及数据对比、流程、公式、结构关系时至少配 1 个可视化组件；
  Callout / Text 不认 `$…$`，公式走 Math 或 Rich；极短确认也包一张卡。先做过一版「禁止整段纯文本」的硬约束，
  按用户意见改回现在的软约束。

### 4. 展开卡片串到相邻对话（777d7c7、35cab64、7cad4b8）

- 用户复报两次，最后一一定位到三条真根因（**都不是组件缓存**）：
  ① 卡片点开是被搬进浮窗的，切会话时旧卡还挂在浮窗上——新增 `_ouiWinConv`，会话变了先收起；
  ② 拦截层 `#ouiScrim` 铺满全屏吃掉第一击，而收起会让被搬走那张的槽位塌成 0 高、列表整体位移，第二击落到隔壁卡；
  ③ 贴底浮窗本身盖住列表下半屏，用户以为点的是下面那张卡，其实点在浮窗上。
- 修法：卡片带 `data-oui-key` 归位、槽位占位（`.oui-slot-held` + `_ouiWinH`）、scrim 改 `pointer-events:none`、
  捕获阶段 `touchstart` 收起 + `touchend` 按坐标补命中（一次点击直接切到指尖下那张卡）、`elementsFromPoint` 穿透定位。

### 5. 回到上次页面 + 首页去掉搜索（a984dd3）

- 冷启动回首页的根因不是 WebView 生命周期：`MainActivity` 每次都重新 `loadUrl`，而 `curTab` 写死 `home`。
  新增 `LS_VIEW("stk.view.v1")` + `saveView()/restoreView()`，落点在 `goTab`、`openLayer/closeLayer`、`planShow/planPageClosed`；
  启动顺序 `planDeepLink() → restoreView()`，考试优先；无效 tab 不再误摘启动页（`var did`）。
- 首页搜索按钮、搜索浮层、`doSearch()` 与相关样式一起删除，`bootGroups()` 少一组（启动动画不会排到已删元素）。

## 三、发布件与下发

- 出包：`gradle assembleRelease`（R8 混淆 + `signing/gime-release.jks` 签名）→ **14,643,182B**，指纹 `00f9da69`；
  `publish.ps1` 写入 `release/GIme-v1.1.6-00f9da69.apk` 与 `release/latest.json`（5 条说明），旧包 v1.1.5 移出 `release/`。
- 门禁：`check-release.ps1` 全 PASS（清单版本/文件名/指纹/字节数/与 `build.gradle.kts` 一致/目录只留当前版本）。
- 回归：`tools/check.mjs` **1179 项**全过（v1.1.5 发布时 1021，本周期 +158）。
- 源码包：`dist/GIme-v1.1.6-source.zip`（不含 `.git`/构建产物/签名材料/机器配置）。
- 发布：GitHub Release `v1.1.6`，两个资产（APK + 源码包），`verify-release.ps1` 全绿。
- 下发：App 判版本走 `api.github.com/contents/release/latest.json?ref=main`，返回 1.1.6 与新包名；
  jsDelivr 四入口与 raw 兜底按新路径拉取（路径带内容指纹，不受 7 天强缓存影响）。

- 真机（白牌 M600 Pro，Android 11，WebView 80）：35 组件矩阵明暗两套 **0 格式警告、0 越界**；
  冷启动 6 场景（题库/错题/我的/对话/方案列表/方案详情）全部还原到原页面；手势面（点卡开窗、窗口开着点另一张一击切换、
  点空白收起、滑动收起）全部通过；全程 0 控制台报错。
- 数据未被破坏：检测期间的探针会话已全部删除，用户的题库、作答记录、方案与对话历史没有被写入。
