### 这一版的包为什么重出过一次

发布前把三笔未推送提交的署名从本机默认身份改成 `HagimeLab <fijin5201314@gmail.com>`
（推送脚本照抄提交身份，不先改就会以本机身份出现在公开仓库上）。
改写只变身份、不变内容：新旧 `main` 的 tree 对象同为 `3245fede`，`git diff` 为空。
但 AGP 会把本地提交号写进 APK 的 `META-INF/version-control-info.textproto`，
所以旧包 `GIme-v1.0.6-2a70b2fe.apk`（指纹就是它的 SHA-256 前 8 位）里嵌的是改写前的提交号。
逐条目比对两个包：137 个条目只有 `version-control-info.textproto` 一项不同，其余 CRC 全等。
发出去的是按当前提交重出的那个（`23c11aed`），旧名不再保留。

## 本版内容

两条新能力：大肥鱼答疑（手机号登录 DeepSeek / API Key 二选一、流式与思考链、历史会话）
与 MCP 接口（外部 agent 读写题库与解析）。逐条说明在 `docs/v1.0.6-发布说明.md`。

- 手机号登录的判据：读到 token 就去问上游 `/api/v0/users/current`，拿到 `mobile_number` 才算真登录。
  用「localStorage 的 token 变没变」判会永远不成立——本来就登录着时 token 早就是真的。
- PoW 的 Keccak 变体（23 轮）纯 Java 多线程现算：本轮实测 20000 次哈希 0.06 秒，
  难度 144000 全窗口 0.4 秒、平均 0.2 秒；上游每个挑战只用一次，所以每请求现取现算。
- MCP 服务从「有开关 + 配置面板」改为默认常开、随应用生命周期起停，面板删除；
  口令仍在应用私有配置里，取用方式是启动日志那一行。
- 工具分发留在页面 JS（`mcpDispatch`），大肥鱼对话复用同一份，不维护第二套 schema。

### 更新分发

`release/latest.json` 只声明当前最高版本；1.0.2–1.0.5 检查更新读清单，
1.0.0 / 1.0.1 读 GitHub `/releases/latest`，两条路都指向 1.0.6。
低版本用户不用先卸载，直接收到这一版。
