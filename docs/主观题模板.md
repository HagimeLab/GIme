# 主观题导入模板（填空 / 解答）

> 用法：照这个格式改完，在 App 里「导入题库 → 选择文件」，或者微信里用 GIme 打开。
> 关键规则：
> - 题干里写「（填空题）」或「（解答题）」，题型就不会被误判成选择题；
> - 主观题用「参考答案：」而不是「答案：」，导入后**不参与自动判分**；
> - 填空的「小结/解析」照常写在「解析：」里；
> - 每题之间空一行，题号写成「第N题」或「N、」都行。

第1题
题目：（填空题）GIme 的题库文件存放在 App 私有目录下的 ______ 目录里。
参考答案：banks
解析：导入的题库统一落在这个目录，换设备需要重新导入。

第2题
题目：（填空题）导入时题库名超过 ______ 个字，会先弹一张改名卡。
参考答案：30
解析：超长不静默截断，先改名再继续；题源仍记原文件名。

第3题
题目：（填空题）大肥鱼识别长文档时，正文超过 ______ 万字会按题号自动分段。
参考答案：1.8
解析：每段不超过 18000 字，切点落在题号行首，段与段的结果合并到同一张确认卡。

第4题
题目：（解答题）为什么导入前建议先留一份纯文本稿？
参考答案：PDF/Word 取字受排版影响，留一份纯文本可以对照排查，分清是排版问题还是取字问题。
解析：主观题可以没有标准答案，但有一份原文对照，改错更快。

第5题
题目：（解答题）这一版是怎么兜住「做题记录凭空消失」的？
参考答案：写盘前比对——新进度为空、磁盘上还有记录、又不是「清空记录」或「删掉最后一个题库」这两条合法路径时，这次不写，把现场记进 stk.diag，并提示已保留原有记录；另外每次写入前留一份备份，开机时主记录为空会用备份恢复。
解析：根因没有复现到，所以这是一道闸加一份证据，不是「已定位的修复」。

第6题
题目：（解答题）大肥鱼导入为什么一定要过确认卡？
参考答案：模型识别出来的题可能缺答案、缺选项，或者把两道题并成一道；确认卡是唯一的落库闸，卡上的题数和题型分布也是唯一的复核口。
解析：确认之前一个字节都不写盘，点「导入」才会调用 saveImportBank。
