# GIme v1.0.5

**这一版只修组卷设置：它只该列当前真正可用的题库。**

## 修了什么

- 组卷的「选择题库」不再列出空题库。题库页对「一道题都没有」的题库本来就是隐藏的，
  组卷这边之前直接遍历全部题库，于是空题库只在组卷里冒出来。
- 删除题库时同步把它从组卷的勾选里摘掉：卷名和「全选 / 全不选」不再把已删题库算进去，
  也不会再在卷名里退回成一串原始 id。
- 如果选中的题库被删了，自动落到第一个有题的题库，不再停在「一个都没选、
  却提示所选题库没有客观题」的状态。
- 组卷可选题库与题库页 / 首页统一口径：至少有一道题。

## 影响范围

只改组卷的选择列表、卷名与勾选状态；题库内容、做题记录、错题、收藏都不受影响。

## 为什么会有这一版

v1.0.4 发布后发现组卷设置会把已删除或未真正加入（一道题都没收录）的题库算进去。
本版是它的热修，只包含这一处改动。

## 验证

- 回归：`tools\check.cmd` 全过（页面逻辑 210 项、发布目录 10 项，Java 各套件全过）；
  新增「组卷只列当前题库」11 项，覆盖空题库、已删/不存在的 id、删库同步摘勾选、
  唯一选中库被删后的回退。
- 真机复现：用一个 0 题空库在旧版上确认——题库页不显示，组卷里却列出「0 题」；
  修复后同一路径不再列出（回归项钉住）。
- 更新链路：见发布记录里的出口读数。

## 安装

覆盖安装即可，做题记录和导入的题库都会保留（与旧版同一张签名证书）。
最低 Android 7.0（API 24）。
