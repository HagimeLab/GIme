## 一、导入去重：题号 → 逐字 → 相似度

同一份文档重跑时，模型分批重发会把题干改写一两个字，原来的「题干+选项」逐字比对认不出来——
真机上同一份 docx 能从 252 题堆到 312。现在三层：

1. **原文题号**（工具新增 `num`）：同一份文档内先按题号去重；但同号而题干相差很远
   （有些文档每章重新编号）仍然收下；
2. **逐字**：题干 + 选项完全一致；
3. **相似度**：题干相似度 ≥ **0.95** 才合并，且只跟同前 8 字前缀桶里的比。

阈值不是拍脑袋：在真实 253 题的库里量过——两道**不同**的题最高能到 **0.898**，
而只改一个标点的同一题是 1.0。所以阈值放 0.95：宁可漏合并，不误合并。

## 二、长文档分段上行

原来正文超过 40000 字只发前 4 万字，剩下的认不回来。现在：

- `splitDocSegments` 按「第N题 / N、」的题号行切段，每段 ≤ **18000 字**；
  切点落在题号行首，不会把一道题劈成两半；拼回去与原文逐字一致；
- 发送时整份文档切成若干段，第一段随消息走，其余留在内存的分段计划里；
- **自动续轮**：这一段交完（本轮新增 0）就自动切下一段，正文换成下一段，
  结果继续并进同一张确认卡；段落全跑完才清计划、放出「取消 / 导入 N 题」；
- 工作气泡显示「正在识别 · 第 k/n 段」；附件条、选择面板的文案跟着改口，
  不再出现「只发前 N 字」。

## 三、顺手修的两处

- 发布检查在开发期不再误报：构建版本高于 release 清单版本时只提示一行，
  相等时仍严格比对（清单比构建新照旧判失败）；
- 切段函数的行首偏移算错一行的 bug（回归里「切点落在题号行上」那条抓到的）。

## 六、刷题页清空本库进度（10-24 13:53）

答题页顶栏、答题卡图标左边多了一颗「↺ 清空本库进度」：

- 点开先弹确认卡，点名题库、写清「已刷 N / M 题」，两个按钮是「取消 / 确认清空」；
- 确认后只清这个库的**做题记录**与**续刷快照**，当前这一组回到第 1 题；
- **错题本标记与收藏保留**——那是复习材料，不该被“重刷”顺手清掉；
- 清的是最后一个有记录的库时，走既有的「合法空写」闸，不会被“防丢记录”拦下来。

真机：临时库答 1 题（卡上 50%）→ 顶栏 ↺ → 确认清空 → 卡上回到 **0%（剩余 2 题）**，
错题本仍是 3 题、别的库不受影响；临时库已删。

## 七、错题本按题库分组

错题本不再把所有库的错题混成一锅：每个库一块，块头是一张卡片（库名 · N 题 · ▾），
右边一颗「刷 N 题」直接开这个库的错题重刷；题库被删后残留的错题单列「已删除的题库」。

- **默认收起**：错题再多也不会把页面拖长；
- 点组头只展开这一组，箭头跟着翻面；**进「管理」也不强行展开**（用户说“管理时也会被强行展开”，
  已改成保持原状，并在批量条下加一句「点题库名可以展开，再勾选要移出的题」）；
- 组内只有这个库的错题，样式与原来一致。

真机：`ict_pdf_test` 1 题 + `gime-test` 2 题，默认两块都收起；点第一块展开、
第二块保持收起；进「管理」后展开状态不变（第一块带勾选框、第二块仍收起）。

回归 **715 项**（新增 9 条：确认卡、清零、保留错题/收藏、别的库不受影响、续刷快照清掉、
当前组回第 1 题、分组标题、组内题数、块内顺序）。

## 九、主观题：先作答再展开参考答案（10-24 14:30）

填空题 / 解答题原来一进来就把参考答案摊开，等于先看答案再作答。现在和选择题同序：
文本框 + **「提交，对照答案」**，点下去才展开参考答案（和解析），随后才是
「还要再看 / 已经掌握」两个自评按钮。

同时按用户要求删掉自评之后那颗 **「改判为待复习 / 已掌握」** 的按钮（作用不大）；
自评本身还在，走「还要再看」即可。提交标记随会话与续刷快照保存，清空本库进度时一并清掉。
背题模式仍然直接展示答案（那本来就是背题的意思）。

真机：填空题练习页一开始只有文本框 + 「提交，对照答案」，没有参考答案；
点提交后出现「参考答案 Service」和两个自评按钮，页面上没有「改判为…」。

回归 **724 项**。

### 参考答案也能收起（10-24 14:44）

上一版提交后参考答案只能展开、不能收起。现在它和「解析」同一种折叠块：提交后默认展开，
点标题收起、再点展开；收起状态按题记在 `S.refShut` 里，切题回来仍是收起的，续刷快照也带上。
解析的折叠头加了 id，避免两个折叠块抢同一个选择器。

真机：填空题提交后「参考答案 ⌃」展开显示 Service；点一下变成「参考答案 ⌄」、内容收起；
再点展开回来。回归 **727 项**。

## 十、主观题：撤掉自评，模拟卷也带上填空/解答（10-24 15:01）

按用户裁定：

- 删掉「还要再看 / 已经掌握」和「改判为…」整套自评（连 `selfCheck` 一起），
  不再有「掌握 / 待复习」状态；**提交一次就算作答过**，只计完成度，
  不判对错、不进错题本、不影响正确率；
- 组卷池不再只抽客观题：**模拟卷里会出现填空题和解答题**（默认的「按题量」模式会抽到；
  「按题型」模式仍只配单选/多选/判断，因为没有它们的数量滑杆）；
- 考试中主观题**交卷前不显示参考答案**；交卷结果标「另有 N 道主观题不计分」，
  得分仍只按客观题算；
- 完成度统一走 `doneCount()`：客观题看判分、主观题看提交。

真机：解答题显示「已作答」标签、参考答案可收起，页面上没有自评按钮；
底部提示改成「提交后对照参考答案；主观题不计对错，也不进错题本」。
回归 **727 项**（组卷池口径翻面，主观题用例按新流程重写）。

### 「按题型分配」补上填空/解答（10-24 15:10）

之前组卷的「按题型分配」只配单选/多选/判断，主观题只能靠「按总题数」随机抽到。
现在五类各一根滑杆（填空/解答默认 **0**，不动原有行为），按题型组卷时也会按数量
把主观题排进卷子；它们不判分，只计入卷面完成度，交卷结果仍标「另有 N 道主观题不计分」。

真机：组卷设置里判断题下面依次是「填空题 0 题（0–4）」「解答题 0 题（0–3）」，
底部提示「五类分别定题数，0 表示不要这类；填空题/解答题不判分，只计入卷面完成度」。
回归 **730 项**。

### 填空答错自动进错题本（10-24 15:26）

按用户裁定走「填空自动比对」：

- 填空题提交时把作答与参考答案**归一化比较**（去空格/标点、忽略大小写）；
  不一致就算错（`w++`、进错题本、`last=0`，并 toast「答错了，已加入错题本」）；
  一致记 `last=1`，但**不会自动移出**错题本（与客观题口径一致）；
- 解答题没有唯一答案，不自动判，仍用「标记错题」手动加；
- 主观题依旧不计入正确率；参考答案仍在提交后才展开。

页面提示也按题型分了：填空「提交后自动对照参考答案；填错会进错题本（不计入正确率）」，
解答「解答题没有唯一答案，答错可点「标记错题」」。

真机：填空键入 `zzz` 后提交 → toast「答错了，已加入错题本」、标签变「已作答」、
参考答案展开为 30、工具条变「移出错题本」。回归 **735 项**。
