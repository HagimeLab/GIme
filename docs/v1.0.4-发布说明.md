# GIme v1.0.4

**这一版把「导入 → 整理 → 刷题」这条路上剩下的磕绊收了一遍：题库能改名，导入更宽容，返回转场不再空白或闪烁。**

## 这一版改了什么

### 题库管理

- 题库卡片左滑有「改名 / 删除」；首页「今日待刷」的题库行也能直接左滑改名或删除
  （之前首页那行只有「删除」，改名只能回题库页找）。
- 改名只动显示名。题目、进度、错题、收藏都挂在题目 id 上，改完不会掉记录；
  题目里的「题源」标记仍写导入时的文件名。
- 改名和删除两格之间加了一条随主题的分隔线。

### 导入

- 认「第 1 题 / 题目： / 答案：」这种排版，题号与标签不再混进题干。
- PDF 导入去掉页末页码；跨行拆开的选项按字母重新拼回同一题，不再并进上一项。
- 导入面板里的「格式说明」换成 App 内可查看、可整份下载的举例页。

### 返回转场

- 返回时卡片不再空白约半秒：幽灵缩到卡片附近时就把真卡片交叉淡入，
  圆角、背景与阴影一起复原。
- 题库页返回时右侧不再闪一下：卡片淡入的那 225ms 是半透明的，
  底下左滑面板会透出来；转场期间给卡片垫同色底、把面板藏起来，收尾还原。

### 更新：旧版本一律指向当前最高版

- 仓库里的 `release/latest.json` 只声明当前最高版本，客户端按段做数值比较版本号；
  不管用户停在 1.0.0 还是 1.0.3，检查更新都会指向 1.0.4。
- v1.0.2 起从清单读版本与安装包名（下载走 CDN 多源）；
  v1.0.0 / 1.0.1 读 GitHub Releases 的最新资产（`/releases/latest`）。
  两条路都落到同一个版本，不做「按版本给补丁」的分发。

## 已知边界

- v1.0.0 / 1.0.1 的下载走 GitHub 资产地址，部分网络下可能慢或打不开；
  v1.0.2 起已改走 CDN 多源，本版沿用。
- 换肤圆形扩散在老内核上的掉帧取舍不变（见 v1.0.3 发布说明），本版没有改动换肤机制。

## 实测

- 回归：`tools\check.cmd` 全过（页面逻辑 199 项、发布目录 10 项，Java 各套件全过）。
- 真机（Android 11 / WebView Chrome 80）：
  - 题库页「继续刷」进入再返回，逐帧录屏深、浅两套主题；
    右半边亮像素占比在淡入段为 0%，修前同一区域出现过整块面板。
  - 首页题库行左滑「改名」能打开面板并保存，重启 App 后名字仍在。
  - 左滑面板的分隔线深浅两套主题各截图核对。

## 安装

覆盖安装即可，做题记录和导入的题库都会保留（与旧版同一张签名证书）。
最低 Android 7.0（API 24）。
