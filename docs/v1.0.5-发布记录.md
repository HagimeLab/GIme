## 本版内容

只有一处：组卷设置只列当前真正可用的题库。逐条说明在 `docs/v1.0.5-发布说明.md`。

- 根因一：组卷选择列表直接遍历 `BANK.subjects`，没有沿用题库页 / 首页的「至少一道题」过滤，
  空题库只在组卷里出现。
- 根因二：删除题库时只摘内存与文件，没有从 `set.paper.subs` 摘勾选；已删 / 不存在的 id
  继续参与「全选」标签与卷名。
- 修法：`paperBanks()` / `paperPrune()`，删库同步摘勾选，卷名按现存题库过滤；
  唯一选中库被删时回退到第一个有题库。

### 真机侧的一处现场观察（未修，留档）

发布前手机上试过更新 1.0.4，下载报「长时间没有进展，已停止」，随后用户在浏览器里打开过发布页。
1.0.5 的下载还没在手机上点过——如果用户点「立即更新」仍卡在同一处，
下一版要看 `Updater.probe` 选源与 DownloadManager 的配合，而不是再换 CDN 顺序。
组卷修复的 UI 复测也要等手机升到 1.0.5 之后再补（当前机上仍是 1.0.3）。
