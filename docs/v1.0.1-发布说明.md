# GIme v1.0.1

维护型小版本：修掉模拟考试流程、题库导入与本地数据保存上的确定性问题，并让更新弹窗能显示更新日志。

**覆盖安装即可，做题记录和导入的题库都会保留**（与 v1.0.0 同一张签名证书，不需要卸载）。

## 改进与修复

- **模拟考试**
  - 最后一题继续往后滑只交卷一次，不会再因为重复交卷报错或出两份成绩。
  - 倒计时归零、点「交卷」、末题滑动现在走同一个交卷入口，防止重复提交。
  - 考试中按返回键会先问一句，可以选「继续考试」「交卷」或「退出并放弃」；放弃后立即停止计时，不会在后台继续走表或自动交卷。
  - 答题页左上角的返回箭头与返回键行为一致。

- **题库导入**
  - 修复从其他应用「打开 / 分享」文件时，冷启动阶段文件被吞掉的问题：现在等页面就绪后再读取，冷启动和运行中分享都能正确导入一次。
  - 明确只支持 **DOCX / TXT / Markdown**；选择旧版 `.doc` 会直接提示不支持，并建议另存为 `.docx`。
  - 导入结果提示里的数字不再自相矛盾：无答案题数量按原始解析结果统计，与「可判分 / 缺选项 / 重复」三项相加等于认出总数。
  - 文件过大（超过 20MB）、文件损坏、无读取权限都会给出可读的原因，而不是把系统异常原文甩到界面上。

- **本地题库保存与删除**
  - 保存题库改为先完整写入临时文件并校验，再安全替换；替换失败时保留原有题库，不会出现「显示导入成功、重启后题库消失」。
  - 删除失败时不再假装删除成功，题库条目会保留并提示重试。
  - 应用异常退出后，下次启动能自动恢复到完整的题库文件。

- **版本更新**
  - 检查到新版本时，弹窗会显示当前版本、最新版本、发布日期和完整更新日志，读完再决定是否更新。
  - 更新日志较长时区域可滚动，底部「稍后 / 立即更新」始终可见。
  - 该版本没有更新说明时显示「此版本暂无更新说明」；检查失败时可一键重试；下载中断会给出原因和重试入口。
  - 「稍后」只关闭弹窗，不会在后台下载。

- **发布安全**
  - Release 构建关闭 WebView 远程调试，避免通过 adb 读写应用内数据。

## 安装说明

1. 下载 `GIme-v1.0.1.apk`。
2. 直接安装覆盖旧版本；首次可能需要在系统设置里允许「安装未知应用」。
3. 安装包校验（可选）：

```
SHA-256: 260C8A93075AC07C17CAA65A6F714A762DA913D6D9B1EE4CFA79358BD71643F4
```

## 已知限制

- 旧版 `.doc` 仍不支持，请用 Word 另存为 `.docx`。
- 内置题库中仍有少量题目存在答案存疑或题干残缺，本次未改动任何题库答案，相关清单见 `docs/explain_review.md`。
